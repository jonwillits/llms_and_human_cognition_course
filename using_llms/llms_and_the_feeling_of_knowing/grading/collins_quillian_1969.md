# Article Content — Collins & Quillian (1969)
## "Retrieval Time from Semantic Memory"

Collins, A. M., & Quillian, M. R. (1969). Retrieval time from semantic memory. *Journal of Verbal Learning and Verbal Behavior*, 8(2), 240–247.

### Application Question

It takes you longer to verify "A canary is an animal" than "A canary is a bird," but verifying "A canary can sing" is faster than verifying "A canary can fly." Explain why, according to this paper's model. Then identify one type of sentence or category that this model would have trouble explaining. What are some details from the study that might apply in this situation, and what are some details that might not transfer to this new situation?

---

## Model Answers and Scoring Criteria

### Question 1: Key Finding

**Model answer:** Reaction time to verify categorical sentences (e.g., "A canary is a bird" versus "A canary is an animal") increased with the number of hierarchical levels separating the subject noun from the category — verifying "A canary is an animal" took longer than "A canary is a bird" because the concept ANIMAL is higher in the hierarchy. Property verification followed the same pattern: "A canary can sing" was faster than "A canary can fly" because the property CAN SING is stored directly at the CANARY node, while CAN FLY is stored at the superordinate BIRD node. These results supported a hierarchical network model of semantic memory in which concepts are organized in taxonomic levels and properties are stored at the highest applicable level to avoid redundant storage.

**Score 2** if the answer conveys both: (a) verification time increased with hierarchical distance for both category membership and property sentences, AND (b) this supports a hierarchical network model of semantic memory with cognitive economy (properties stored at the most general applicable level).

**Score 1** if the answer correctly describes the reaction time gradient (further = slower) but does not connect this to the hierarchical network model, or correctly identifies the hierarchical network model without clearly describing the reaction time evidence that supported it.

**Score 0** if the answer is vague, incorrect, or blank — for example, says only "some sentences are faster to verify than others" without the specific hierarchical distance mechanism.

### Question 2: Method

**Model answer:** Participants were presented with sentences on a display — sentences of the form "A [noun] is a [category]" (e.g., "A canary is a bird," "A canary is an animal") or "A [noun] can [property]" (e.g., "A canary can sing," "A canary can fly"). Participants pressed one button if the sentence was true and another if it was false, as quickly and accurately as possible. Reaction time was the primary dependent variable. The sentences systematically varied the hierarchical distance between the subject noun and its category or property in the assumed semantic network. False sentences (e.g., "A canary is a fish") were included as control items.

**Score 2** if the answer conveys both: (a) participants verified true/false sentences by button press as quickly as possible, AND (b) the key manipulation was hierarchical distance between noun and category/property, with reaction time as the dependent variable.

**Score 1** if the answer describes the sentence verification task but omits the hierarchical distance manipulation, or describes the manipulation without clearly indicating that reaction time was the key measure.

**Score 0** if the answer is vague, blank, or fundamentally wrong — for example, describes this as a recall or learning study, or as an experiment where participants learn new categories rather than verify known ones.

### Question 3: Broader Concept

**Model answer:** This paper illustrates the hierarchical network model of semantic memory — the idea that human conceptual knowledge is organized as a taxonomic network in which concepts are linked to superordinate categories, and properties are stored at the highest level to which they apply (cognitive economy). Verifying a property requires traversing the network from the noun to the node where the property is stored; longer traversal times reveal the underlying structure. This was one of the first attempts to use reaction time as a window into the organization of long-term memory, and it influenced decades of subsequent work on semantic memory, spreading activation, and the representation of conceptual knowledge.

**Score 2** if the answer identifies both: (a) the hierarchical network model with cognitive economy (properties stored at the most general level), AND (b) why this matters — either by noting its implications for how semantic knowledge is organized, how properties are inherited, or how it contributed to cognitive science more broadly.

**Score 1** if the answer correctly names a network model of memory without explaining the hierarchical/economy principle, or correctly identifies cognitive economy without describing how the network model accounts for the reaction time data.

**Score 0** if the answer misidentifies the concept (e.g., describes it as a study about working memory or attention) or is too vague to demonstrate understanding.

### Question 4: Apply

**Model answer:** According to Collins & Quillian's model, CANARY is linked directly to BIRD, which is in turn linked to ANIMAL. Verifying "A canary is an animal" requires traversing two links (CANARY → BIRD → ANIMAL), while verifying "A canary is a bird" requires only one link (CANARY → BIRD). More links mean more retrieval time.

For properties: CAN SING is stored directly at the CANARY node because it is a distinctive canary property, so verification requires only one step. CAN FLY is stored at the BIRD node (because most birds fly and it would be redundant to store it at every bird), so verifying it for a canary requires traversing up to the BIRD node — one step more, hence slower.

A case that the model would have trouble explaining: atypical category members. "A penguin is a bird" should take the same amount of time as "A robin is a bird" according to the model (same hierarchical distance), but people verify "A robin is a bird" faster — suggesting typicality matters in ways the hierarchical network does not capture. Similarly, properties that are associated but not strictly inherited through the hierarchy (e.g., "A bat can fly" — bats are mammals but share a flight property typically stored under BIRD) create problems for a purely hierarchical storage scheme.

What transfers: The core question — explaining why some verification judgments are faster than others — is directly served by the paper's model, and the canary/animal/bird and canary/sing/fly examples are taken directly from the paper.

What may not transfer: The model describes reaction times for verifying known facts about natural concepts, based on tasks administered in a lab. In everyday reasoning, people draw on context, pragmatics, and prior discourse — not just abstract semantic networks. Additionally, later research showed the model has difficulty with typicality effects and category exceptions, which the original paper did not fully address.

**Score 2** if the answer (a) correctly explains both the category-membership and property examples using hierarchical distance and/or cognitive economy, AND (b) identifies at least one type of sentence or category the model would struggle with (e.g., atypical members, exceptions, non-hierarchical associations).

**Score 1** if the answer correctly explains one of the two examples (category membership or property retrieval) but not both, or explains both correctly but does not identify any limitation of the model.

**Score 0** if the answer does not engage with the hierarchical distance explanation, or identifies a "problem case" that is not actually a problem for the model.
